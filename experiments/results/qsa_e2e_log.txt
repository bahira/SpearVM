### Debit mesure (et pourquoi on n'extrapole pas ici)
  memoire          : 2482 -> 2282 -> 2114 tok/s (N croissant), soit 2114 tok/s a N=8192
  spur             : 3084 -> 2792 -> 2980 tok/s (N croissant), soit 2980 tok/s a N=8192
  spur groupe 16   : 12728 -> 18901 -> 20772 tok/s (N croissant), soit 20772 tok/s a N=8192
  Le debit MONTE avec N pour les variantes groupees : le surcout
  Python par tuile s'amortit. Un ajustement en loi de puissance
  donnerait un exposant < 1, ce qui n'a aucun sens physique — le
  terme de routage finira par dominer. On ne l'extrapole donc pas :
  la loi d'echelle rigoureuse est celle du COMPTAGE d'operations
  (bench_hier.py), pas celle du temps de paroi a ces tailles.
